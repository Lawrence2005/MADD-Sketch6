# MADD 26210 Sketch 6

For this sketch, I explored whether a machine learning model could generate something that feels natural without directly drawing or photographing nature. I trained a Variational Autoencoder (VAE) on a dataset of natural landscape images. The goal was to make the model learn the visual structure of landscapes — sky, land, water, mountains, light, and color — and then generate new images from its latent space.

The results were only partially successful. The reconstructions improved over training, and the model was able to preserve some broad features of the original images, such as sky/ground separation, warm sunset colors, dark mountain silhouettes, and blue water or sky regions. However, the reconstructions remained very blurry. They captured the general atmosphere of the input images more than the actual details. Sharp features like trees, rocks, waves, buildings, or mountain edges were mostly lost.

The random generations were even more abstract. The model generated soft, blurry fields of blue, green, yellow, gray, and brown. These images do not look like real places, but they do have a nature-like color palette and atmosphere. In that sense, the model produced something closer to a “memory” or “impression” of landscape rather than a realistic landscape image.

The VAE did not fully recreate nature; instead, it compressed nature into a low-dimensional latent space and returned it as blur, color, and vague structure. Technically, the model learned patterns from the dataset, but aesthetically, the output became abstract and unstable. The images are not natural scenes, but digital approximations of naturalness.

If I continued this project, I would try using a narrower dataset, such as only mountains, only beaches, or only sunsets, so the model would not have to learn so many different landscape types at once. I would also try a stronger architecture or a different generative model. Still, the current result is useful because it shows how machine learning can produce an artificial version of nature: not a copy of the world, but a blurry computational reconstruction of it.
